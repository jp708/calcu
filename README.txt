# Calculadora en C++

Este ZIP contiene:

- **index.html** : Página con resumen de conceptos básicos de C++ (estilo W3Schools) + explicación del código.
- **style.css** : Estilos.
- **calculadora.cpp** : Código fuente de la calculadora.

## Conceptos cubiertos en la página

- Variables y tipos de datos
- Operadores
- if / else
- switch
- Bucles while y for
- Funciones
- cin y cout

## Cómo usar

1. Abre `index.html` en el navegador.
2. Para ejecutar la calculadora:

```bash
g++ -o calculadora calculadora.cpp -std=c++17
./calculadora
```
